# SC-004: Compare Master Version Running Side by Side

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Instantly pull up the master version of the code and compare it running side by side with the current version.

## Details (from design sketch)

- Debugging window with **Show App** toggles: ☑ Main, ☑ Current.
- The debugging window is toggled from a button on the right controller.

## Acceptance Criteria

- [ ] User can launch the master/main build of the app with one action.
- [ ] Main and Current builds can run at the same time in separate windows.
- [ ] Debugging window has toggles to show or hide Main and Current.
- [ ] Right controller button toggles the debugging window.
- [ ] Builds on [SC-005](SC-005-interactive-app-windows.md).
