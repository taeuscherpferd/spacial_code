# SC-006: Select a UI Element to See Connected Code

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Select a UI element in a running app window and see which areas of code it's connected to.

## Acceptance Criteria

- [ ] User can enter an "inspect" mode in a running app window.
- [ ] Selecting a UI element finds its source component/file.
- [ ] Connected code is highlighted in the tree (reusing [SC-003](SC-003-highlight-code-connections.md)).
- [ ] Depends on [SC-005](SC-005-interactive-app-windows.md).
