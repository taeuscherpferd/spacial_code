# SC-007: Master and Change-Set Code Trees Side by Side

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Show the master code tree and the change-set code tree side by side.

## Acceptance Criteria

- [ ] Two trees can be rendered at once: master and the current change set/branch.
- [ ] Added, modified, and deleted files/nodes are visually marked.
- [ ] Selecting a node in one tree highlights the matching node in the other.
- [ ] Depends on [SC-001](SC-001-vr-code-trees.md).
