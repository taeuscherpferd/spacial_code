# SC-003: Highlight Everything a Line or Function Touches

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Select a line of code or a function and have it highlight everything it touches in the tree.

## Acceptance Criteria

- [ ] User can select a single line of code or a whole function.
- [ ] All callers, callees, and referenced symbols/files are highlighted in the tree.
- [ ] Highlighting is visually distinct and can be cleared.
- [ ] Depends on the logical/calling tree from [SC-001](SC-001-vr-code-trees.md).
