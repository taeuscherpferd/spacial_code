# SC-010: Place Windows Anywhere

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Place windows wherever you want in the VR space.

## Details (from design sketch)

Controller mapping (right controller):
- Button: **Toggle debugging window**
- Trigger: **Select**
- Grip: **Grab**

## Acceptance Criteria

- [ ] Any window (code, app, debugging, assistant) can be grabbed and moved.
- [ ] Windows can be resized and rotated.
- [ ] Window layout persists between sessions.
