# SC-005: Fully Interactive Running App Windows

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Have fully interactive windows of the app running and viewable inside the VR environment.

## Acceptance Criteria

- [ ] The app under development can be run and shown in a window in VR.
- [ ] The window accepts full input (pointer, click, scroll, keyboard).
- [ ] The window updates live as code changes.
- [ ] Windows can be placed anywhere (see [SC-010](SC-010-place-windows-anywhere.md)).
