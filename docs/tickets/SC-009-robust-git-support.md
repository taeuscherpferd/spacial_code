# SC-009: Robust Git Support

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Robust Git support: see the full history of a file or piece of code, read commit details, blame each line of code, and turn back time if you want. All this context should be available to the agent as well.

## Acceptance Criteria

- [ ] View full commit history for a file or selected code range.
- [ ] Read commit details (message, author, date, diff).
- [ ] Per-line blame view.
- [ ] "Turn back time": view/check out the tree at a previous commit.
- [ ] History, blame, and commit data are available to the assistant ([SC-002](SC-002-context-aware-assistant.md)).
