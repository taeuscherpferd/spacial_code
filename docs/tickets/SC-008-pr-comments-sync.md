# SC-008: Code Comments Synced to PRs (Azure DevOps & Git)

**Status:** Not started
**Roadmap:** [roadmap.md](../roadmap.md)

## Summary

Leave comments on the code that can be synced to PRs in Azure DevOps and Git hosts.

## Acceptance Criteria

- [ ] User can attach a comment to a line or range of code in VR.
- [ ] Comments sync to an Azure DevOps PR as review comments.
- [ ] Comments sync to a Git-hosted PR (e.g. GitHub) as review comments.
- [ ] Existing PR comments are pulled in and shown in place.
